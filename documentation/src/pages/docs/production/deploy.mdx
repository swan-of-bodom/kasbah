# Deploy [Run it on a server]

`kasbah start` needs `DATABASE_URL`: it never starts a container itself.

## Docker Compose

`init` writes a `Dockerfile` and a `docker-compose.yml`: Postgres and the indexer, health-checked, the API on
`127.0.0.1:42069` for a proxy in front.

```bash
docker compose up -d
```

## Railway, Render, Fly

1. Add a Postgres database.
2. Add a service from your repository (it builds with the `Dockerfile`).
3. Set `DATABASE_URL` and `KASBAH_RPC_URL`. The platform's `PORT` is used automatically.
4. Use `/health` as the health check.

## Several API servers

Run one `start` and as many `serve` processes as you need: they read the same database.
