# Render [Deploy with a Render Postgres]

::::steps

### Push your project to GitHub

Render builds it from `package.json`: no Dockerfile needed.

### Create the database

**New → Postgres**. Once it's up, copy its **Internal Database URL**.

### Create the service

**New → Web Service**, pick the repository, **Language: Node**, in the same region as the database.

| Setting | Value |
| --- | --- |
| Build Command | `pnpm install --frozen-lockfile` |
| Start Command | `pnpm start` |

With npm: `npm install` and `npm start`.

### Set the variables

| Variable | Value |
| --- | --- |
| `DATABASE_URL` | the Internal Database URL |
| `KASBAH_RPC_URL` | your RPC URL |
| `DATABASE_SCHEMA` | `my_indexer` |

`PORT` is set by Render and used automatically.

### Health check

**Advanced → Health Check Path**: `/health`.

::::

Render keeps the old instance running until the new one is healthy, so on a code change both run at once. Change
`DATABASE_SCHEMA` with every build (`my_indexer_v2`, …), as in
[one schema per deploy](/docs/production/self-hosting#one-schema-per-deploy).
