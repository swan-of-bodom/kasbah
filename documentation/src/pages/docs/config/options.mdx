# Options [Finality, cache, API and database settings]

Every option with its type and default is in the [config reference](/docs/reference/config).

```ts [kasbah.config.ts]
export default kasbah({
  network: "mainnet",
  rpc: process.env.KASBAH_RPC_URL!,
  contracts: { /* … */ },
  finality: "l1",
  cache: false,
  api: {
    port: 42069,
  },
});
```

## Finality

- `reorgWindow`: blocks behind the head that a reorg can still replace. Default `64`. They're indexed with an undo
  journal, so a reorg undoes them.
- `finality: "l1"`: a block is final only once Ethereum accepted it, a few hours behind the head. Use it when your
  app must never show data a reorg could take back. Don't set both.

## Cache

- On by default: final raw events and contract reads are kept in Postgres (schema `kasbah_cache_<chain>`), shared
  by every app on the chain, so a re-index fetches nothing again. `{ maxCalls }` caps the reads kept (default
  1,000,000).
- It costs disk: about 400 bytes per event, indexes included (50M Ekubo events took 19 GB), so a busy contract's
  whole history can take tens of GB. `cache: false` turns it off; `kasbah cache clear` deletes what it holds.

```bash
kasbah cache info
kasbah cache clear --events
```

## API and database

- `api`: `{ port, host, readDatabase }`, or `false` to turn the API off. Defaults to port 42069 on localhost.
- `database`: a Postgres URL. Default: `DATABASE_URL`.
- `schema`: the Postgres schema for the app's tables. Default for `dev`: the project directory's name; `start` and
  `serve` need one (here, or `--schema`, or `DATABASE_SCHEMA`).
- `tables`: default, what `kasbah.schema.ts` exports.
