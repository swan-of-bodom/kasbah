# GraphQL [A GraphQL API generated from your tables]

`app.use("/graphql", graphql({ db, schema }))` in `src/api/index.ts` serves `POST /graphql`, with GraphiQL at
[localhost:42069/graphql](http://localhost:42069/graphql) in a browser. The schema is Ponder's, so a Ponder client
or query works as is.

```graphql
{
  pools(where: { swaps_gt: 100 }, orderBy: "swaps", orderDirection: "desc", limit: 10) {
    items {
      id
      swaps
    }
    pageInfo {
      hasNextPage
      endCursor
    }
    totalCount
  }
  pool(id: "0x…") {
    liquidity
  }
}
```

Per table, by its name in `kasbah.schema.ts` (`export const pool = pgTable(…)`), two fields: `pool(<primary key>)`,
the row or `null`, and `pools`, a page. Fields are the table object's keys.

| Argument | Description |
| --- | --- |
| `where` | `{ column: value }`, `_not`, `_in`, `_not_in`; numbers `_gt`, `_gte`, `_lt`, `_lte`; strings `_contains`, `_starts_with`, `_ends_with`, their `_not_` forms and `_nocase` forms (not for `hex()`); arrays `_has`, `_not_has`; `AND` and `OR` lists. `null` matches `IS NULL` |
| `orderBy`, `orderDirection` | a column's name, `"asc"` (default) or `"desc"`; the primary key breaks ties |
| `limit` | default 50, at most 1,000 |
| `after`, `before` | a page's `pageInfo.endCursor` or `startCursor` |
| `offset` | rows to skip, without a cursor |

`bignum()` and `int8({ mode: "bigint" })` columns are `BigInt`, written as strings (`"1000"`); `numeric()` is
`Numeric`, a string too. `totalCount` counts every row the filter matches, and runs only when asked for.

## Paging

```graphql
query ($after: String) {
  pools(orderBy: "swaps", orderDirection: "desc", limit: 100, after: $after) {
    items { id swaps }
    pageInfo { hasNextPage endCursor }
  }
}
```

Pass `endCursor` as `after` until `hasNextPage` is false; `startCursor` as `before` goes back.

## Relations

Drizzle `relations()` exported from `kasbah.schema.ts` become fields: a `one()` is the related row (a page's are
loaded in one statement), a `many()` a page with the same arguments as `pools`. A `many()`, and a `one()` without
`fields`, take their columns from the `one()` back.

## Indexing status

```graphql
{ _meta { status } }
```

`status` is what `GET /status` returns.

## Limits

A request can have at most 1,000 tokens, a depth of 100 and 30 aliases (`graphql({ db, schema }, { maxOperationTokens,
maxOperationDepth, maxOperationAliases })` changes them). The rows one request reads may take at most a sixteenth of
the API's heap, it may run at most 500 SQL statements (a `many()` runs one per parent row), four at a time, and all
of them within the query timeout; past any of these, it gets an error instead.

## Errors

A mistake in the query (a bad cursor, a limit over 1,000, a value Postgres refuses, a limit above) comes back with its
message. Any other error comes back as `Unexpected error.`, and the process logs it; `kasbah dev` shows it in full.
