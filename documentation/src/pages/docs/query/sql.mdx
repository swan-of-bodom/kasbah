# SQL over HTTP [Query your tables with SQL]

```bash
curl localhost:42069/sql \
  -d '{"sql": "SELECT id, swaps FROM pools ORDER BY swaps DESC LIMIT $1", "params": [10]}'
```

```json
{ "columns": ["id", "swaps"], "rows": [["0x…", 812]] }
```

## Rules

- One `SELECT` (or `WITH`, `VALUES`), on the app's tables only, through a role that can only read them.
- `$1`, `$2`… are `params`.
- A 10 s timeout, and at most 10,000 rows: more is an error (`more than 10000 rows: add a LIMIT`).
- Errors come back as `{ "error": "…" }` with a 4xx status.

To query from your own tools, see [Direct SQL](/docs/database#direct-sql).
