# Live queries [Get results pushed when they change]

`GET /live` is a server-sent events stream. With `sql` or `query`, it sends that query's result whenever it changes.

```ts
const url = "http://localhost:42069/live?sql=" + encodeURIComponent("SELECT count(*) FROM pools");
const events = new EventSource(url);
events.addEventListener("result", (e) => console.log(JSON.parse(e.data)));
```

Without a query, it sends `checkpoint` events: the last indexed block, after each commit.
