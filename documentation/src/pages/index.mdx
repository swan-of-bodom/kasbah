# kasbah [A minimal, fast Starknet indexer in TypeScript]

Index Starknet contracts into Postgres, and query them over GraphQL or your own endpoints.

```ts
app.on("Core:Swapped", async ({ event, context }) => {
  await context.db.insert(swaps).values({
    id: `${event.transaction.hash}:${event.index}`,
    amount: event.args.delta.amount0.mag,
  });
});
```

- **Typed from the ABI**: event arguments, contract reads and config are checked by TypeScript, with no code generation.
- **Fast backfill**: parallel `getEvents` windows, a raw-event cache, and filters the node applies.
- **Reorg safe**: blocks near the head are undone and redone when the chain changes.
- **Factories, block handlers, contract reads, transactions and receipts.**
- **A read API on Hono**: GraphQL with relations, and your own endpoints.
